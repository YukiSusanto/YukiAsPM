# AI 会话质检需求文档

> 本文档以当前 AI 会话质检原型为基线，只记录当前确认并需要持续维护的产品需求。

| 模块 | 需求说明 | 原型图 |
|---|---|---|
| 页面框架 | 提供与雪梨英语管理系统一致的 AI 会话质检工作台。<br>• 顶部展示系统名称、当前位置、通知和当前用户。<br>• 左侧提供主导航并高亮“AI 会话质检”。 | <img src="./images/AI会话质检-基线原型.jpg" width="320" alt="AI会话质检基线原型"> |
| 时间与添加时间筛选 | 支持按指定时间范围和客户添加时间查看销售企微会话。<br>• 标题下方独立说明聊天记录时间范围用于限定右侧会话查询、历史加载和导出范围。<br>• 提供今天、昨天、近 7 天快捷选项，支持设置开始和结束日期并刷新结果。<br>• 选择客户时，在刷新按钮旁依次展示“添加时间：”、新客户和老客户；悬停新客户或老客户按钮时，提示对应的添加时间定义。 | <img src="./images/AI会话质检-添加事件筛选提示.jpg" width="320" alt="添加时间筛选提示原型"> |
| 客户标签筛选 | 支持按企业微信标签组选择一个或多个客户标签并筛选客户。<br>• 标签组及标签名称沿用“企业微信标签管理”的数据口径，并显示标签组总数。<br>• 点击“客户标签”选择框打开左右结构筛选弹层，左侧展示标签组，右侧展示组内标签，两侧均支持按名称搜索。<br>• 支持全选或取消全选当前标签组；弹层顶部紧凑展示已选标签。确认后选择框展示前两个标签及剩余数量，悬停时显示完整标签。<br>• 同一标签组内按“或”匹配，不同标签组之间按“且”匹配；切换到群聊时不展示客户标签筛选。 | [查看原型](../index.html) |
| 销售企微账号 | 展示销售企微账号列表，并支持快速定位目标账号。<br>• 显示账号总数、头像、账号名称和企微 ID。<br>• 支持搜索、收藏、选择账号和列表翻页。 | <img src="./images/AI会话质检-基线原型.jpg" width="320" alt="销售企微账号原型"> |
| 外部联系人 | 按客户和群聊两个大类展示当前销售账号关联的外部联系对象。<br>• 客户分类提供全部、未流失、已流失状态筛选；群聊分类提供全部、已解散状态筛选。<br>• 列表显示对应总数、头像、名称、最近消息和更新时间，并支持搜索、收藏、选择和翻页。 | <img src="./images/AI会话质检-基线原型.jpg" width="320" alt="外部联系人原型"> |
| 会话信息栏 | 展示当前客户信息并提供会话内容检索。<br>• 显示客户头像、名称、只读状态和收藏操作。<br>• 支持搜索当前时间范围内的聊天内容，并展示消息总数。 | <img src="./images/AI会话质检-基线原型.jpg" width="320" alt="会话信息栏原型"> |
| 只读会话 | 以只读方式还原客户与销售侧的历史聊天记录。<br>• 客户消息在左侧展示，销售、AI 或 APP 消息在右侧展示。<br>• 每条消息显示发送方、来源、时间和消息内容，不提供输入或发送能力。 | <img src="./images/AI会话质检-基线原型.jpg" width="320" alt="只读会话原型"> |
| 会话内容展示 | 支持在消息流中清晰展示不同类型和长度的内容。<br>• 文本保留换行、链接、表情和长内容结构。<br>• 消息区域独立滚动，当前选中客户的会话保持连续可读。 | <img src="./images/AI会话质检-基线原型.jpg" width="320" alt="会话内容展示原型"> |
| 历史消息加载与定位 | 会话记录按每批 50 条自然向上加载，不再使用分页。<br>• 进入会话先请求并展示最新 50 条；滚动到顶部时继续请求更早的 50 条并加入本地缓存，保持当前阅读位置，直到所选时间范围内的最早消息。<br>• 收藏按钮右侧提供“切换至最早消息”，加载全部历史后自动滚动至顶部；悬停说明最早消息以左上角所选时间范围的最早时间为准。<br>• 会话右下角提供三箭头圆形按钮，可一键回到最新消息。 | [查看原型](../index.html) |
| 会话导出配置 | 支持基于所选员工、时间范围和客户范围创建会话导出任务。<br>• 顶部“已是最新”旁提供无图标的“导出会话”入口，并预留“导出客户信息”入口，后者的具体导出内容待确认。<br>• 导出员工默认当前所选企微员工且只能单选，日期默认使用页面聊天记录时间范围并精确到日；任务名称默认由员工企微名称和导出日期范围组成，并允许修改。<br>• 导出格式和客户范围均使用紧凑的左右分段单选；格式支持“导出到一个表格”和“每个客户一个表格”，范围支持当前企微账号下全部客户或指定客户。<br>• 指定客户时可打开客户选择页并多选客户；客户标签筛选沿用页面外层的左右分栏选择器，支持标签组和标签搜索、组内全选、多标签选择及已选回显。<br>• 客户选择列表展示企微头像、名称、标签、添加人和添加时间。 | [查看原型](../index.html) |
| 导出 Excel 字段 | 导出的会话明细使用固定的 11 列字段。<br>• 字段依次为：发送途径、会话信息、发送人、发送人身份、会话内容、接收人、接收人身份、客户手机号、客户备注名、发送时间、添加时间。<br>• 会话信息由销售名称、导出时间和客户名称组成；会话内容每条消息占一行并保留单条聊天的完整内容。<br>• 发送人和接收人根据消息方向分别填写销售企微名称或客户名称，身份统一为“客户”或“员工”。<br>• 发送途径仅员工消息填写，取值为 APP、AI、SOP、人工；客户消息留空。添加时间指客户添加销售企微好友的时间。 | [查看原型](../index.html) |
| 底部分页栏 | 在工作区底部提供账号列表和客户列表的翻页能力。<br>• 分别展示账号页码和客户页码。<br>• 会话区域只显示已加载数量及上滑加载提示，不提供页码、每页条数或页码跳转。 | <img src="./images/AI会话质检-基线原型.jpg" width="320" alt="底部分页栏原型"> |
