# AI 销售助手页面复刻

基于浏览器中打开的雪梨英语生产页面复刻，重点为右侧客户画像。采用原生 HTML、CSS、JavaScript，无构建依赖。

## 启动

在此目录运行 `npm run dev`，访问 http://127.0.0.1:5173 。

## 已实现

- 系统导航、员工选择、客户会话列表、聊天区域和右侧客户画像的布局。
- 客户画像的资料、用户分析、订单记录、学习情况四个标签页。
- 基本信息、企微备注编辑、员工及标签、所在社群、消费汇总。
- 订单搜索、全量价格降序、课程名主标题、课程开课状态标签。
- 客户搜索及切换、未读/未回复筛选、侧栏收起与展开、侧栏及会话栏宽度拖动。
- 会话记录、草稿、表情、演示消息发送、发送区高度拖动。

## 数据范围

这是本地交互复刻，未连接生产接口。仅“特立独行”示例包含参考页面中观察到的订单和学习记录；其他客户显示空订单，避免借用错误的客户数据。手机号已脱敏。发消息、修改备注、标签和 AI 开关均只修改当前本地页面状态，刷新后复位。附件只演示文件选择及文件名，不进行上传。头像使用观察到的远程资源，其余为占位头像。

## 检查

`npm run check` 检查 JavaScript 语法。页面交互和视觉以浏览器实测为准。

## 客户动态

在用户分析后新增客户动态标签，移植参考原型的员工、操作平台、动态类型联动筛选及倒序事件时间线。不包含参考原型上方的员工选择卡、销售标签、客户概要和事件添加功能。13 条参考事件只绑定特立独行作为界面演示，不代表该客户的真实行为，也不与生产订单关联。其他客户显示空状态，各客户筛选条件独立保留。
