# AI 销售助手 · SOP 轨迹需求文档

| 模块 | 需求说明 | 原型图 |
| --- | --- | --- |
| 右侧栏 · SOP轨迹入口 | **在「会话记录」右侧新增「SOP轨迹」页签，查看当前客户的触达记录。**<br>1. 顶部显示当前客户昵称和筛选项，时间线区域独立滚动。<br>2. 切换客户时同步更新轨迹；客户无记录时显示「该客户暂无 SOP 轨迹」。 | |
| SOP轨迹 · 时间线 | **将预触达和已触达放在同一条时间线上，按时间倒序展示。**<br>1. 预触达使用计划触达时间，已触达使用实际触达时间，均按北京时间展示。<br>2. 卡片以发送动作为标题，并展示状态、期数、阶段编码和最多两行话术摘要。 | |
| SOP轨迹 · 状态筛选 | **支持「全部」「预触达」「已触达」单选筛选，各选项显示对应条数。**<br>1. 默认选中「全部」；选择某个状态后仅保留对应记录，沿用时间倒序。<br>2. 按客户记忆筛选项；筛选无结果时提示当前状态暂无记录。 | |
| SOP轨迹 · 触达详情 | **点击卡片内的「触达详情」展开完整内容和触发条件。**<br>1. 展示阶段编码、时间规则、计划和实际触达时间；预触达的实际时间显示「待触达」。<br>2. 展示完整话术、消息物料、包含和排除规则、匹配说明，以及有值时的运营备注。 | |
