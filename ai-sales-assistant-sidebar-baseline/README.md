# AI销售助手侧边栏基线

本分支以首次复刻时观察到的生产界面为起点。侧边栏包含「资料、用户分析、订单记录、学习情况」四个标签页。初始版本根据首次复刻记录和最早入库的原型源码还原，使用演示数据。

- 维护基线时，以生产环境实际页面为准。同步提交记录观察日期及对应的页面变化。
- 新需求从基线分支另建功能分支，需求改动留在各自的开发分支。功能实际进入生产后，再将生产页面的对应变化同步到基线。
- 在仓库中使用本目录作为侧边栏基线原型的入口。

双击 `index-standalone.html` 可离线预览。在本目录运行 `npm run dev` 可通过 http://127.0.0.1:5174/ 预览源码版。修改后运行 `npm run build:standalone` 更新单文件版。
